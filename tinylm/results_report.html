Overview

We replicated the TinyStories paper (Eldan & Li, 2023) using Karpathy's llama2.c codebase, successfully training a 260K parameter Llama 2 model that generates coherent children's stories. We then conducted a systematic architecture search at sub-1M parameter scale — varying width, depth, vocabulary size, looped transformers, input injection, and knowledge distillation — to find optimal configurations for IoT deployment on resource-constrained devices.

This is the first study to systematically map these tradeoffs at extreme sub-1M scale. All prior work (MobileLLM, TinyStories, etc.) either studied larger scales or only tested a few fixed configurations.

Experimental setup
Architecture: Llama 2 (RMSNorm, SwiGLU, RoPE, GQA)
Dataset: TinyStories (2.1M stories, ~7GB)
Tokenizer: SentencePiece BPE, vocab=512
Optimizer: AdamW (lr=5e-4, cosine decay)
Training: 5,000 steps, batch=128, grad_accum=4
Sequence length: 256 tokens
Hardware: RTX 3070 Ti 8GB, Ryzen 7 7700X
Time per run: ~40 minutes

Key Findings

1
Width beats depth below 1M parameters. Model D (dim=96, 5 layers) beat Model E (dim=64, 8 layers) despite similar param counts. Model G (dim=128, 3 layers) beat D. Model H (dim=192, 2 layers) beat G. This contradicts MobileLLM (Meta, 2024) which found depth beats width at 125M+. The crossover lies between 1M and 125M.
2
Two layers is the minimum for coherent generation. Model I (dim=256, 1 layer, ~1.0M) was significantly worse than Model H (dim=192, 2 layers, ~1.0M) at the same param budget (1.3774 vs 1.2344). A single attention+FFN pass cannot build deep enough representations regardless of width.
3
Looped transformers achieve competitive quality at half the parameters. Loop 2x3 (~250K) nearly matched baseline A (~260K): 1.5452 vs 1.5695. Uses 2 unique blocks reused 3 times. First test of this technique below 1M params. Based on "Fully Looped Transformer" (arxiv 2605.18797, May 2026).
4
Input injection (Mythos-style) hurts at ultra-small scale. Adding input embeddings back at each loop made Loop 2x3 worse: 1.7975 vs 1.5452. At billions of params this prevents hidden state drift. At 250K with dim=96, injection overwrites learned features — acts as noise.
5
Knowledge distillation doesn't help at sub-500K scale. Student (260K) trained with soft labels from teacher Model D (500K) performed worse than training from scratch: 1.6357 vs 1.5695. The student lacks capacity to both learn language AND mimic the teacher's distribution.
6
Vocabulary must stay tiny at this scale. Increasing vocab from 512 to 1024 to 2048 steadily degraded results (1.57 → 2.12 → 2.29). At dim=64 with vocab=2048, the embedding table alone consumes 35% of total parameters.
7
~200K parameters is the minimum for coherent English. Model F (110K) produced mostly broken sentences. Baseline A (260K) was the smallest model generating recognizable stories. The coherence cliff sits around 200K params with this architecture and dataset.
